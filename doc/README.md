# Documentation du projet
+
Ce fichier liste et décrit brièvement les documents présents dans le répertoire `doc/` pour faciliter la navigation depuis la racine du dépôt.
+
## Documents principaux

- `configuration.md` — Paramètres et variables d'environnement nécessaires au projet.
- `dev.md` — Guide pour installer et lancer l'environnement de développement.
- `installation.md` — Instructions d'installation détaillées (Nix et alternatives).
- `integration.md` — Notes relatives au déploiement et à l'intégration.
- `makefile.md` — Description des commandes `make` utiles pour le projet.
- `nixpkgs.md` — Informations sur le packaging Nix/Nixpkgs utilisé.

## Documents secondaires

- `architecture.md` — Diagrammes et décisions architecturales.
- `continuous.md` — Configuration CI / pipelines d'intégration continue.
- `docker.md` — Utilisation et images Docker associées.
- `nixos4django.md` — Conseils et exemples pour déployer Django sur NixOS.

Si un document manque de description ou doit être réorganisé, ouvrez une issue pour proposer des précisions.
